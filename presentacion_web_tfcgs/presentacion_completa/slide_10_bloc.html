Arquitectura: Similar a MVC

Patrón BLoC
Organización del código similar al MVC visto en el ciclo: separar vista, lógica y datos.
Separación Clara
Archivos independientes para pantallas (UI) y para la lógica que procesa las acciones.
Fácil Mantenimiento
Si hay que modificar algo, es sencillo localizar dónde hacerlo sin afectar otras partes.

Comparación MVC vs BLoC

MVC (del ciclo) BLoC (Flutter) Función
Vista Widget / UI Lo que ve el usuario
Controlador BLoC Procesa acciones y lógica
Modelo Estado Los datos del momento

La misma filosofía de separación de responsabilidades, adaptada a Flutter.
