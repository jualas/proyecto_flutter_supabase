# Sistema de Seguimiento de Proyectos TFCGS - Presentación Web

Presentación interactiva para la defensa del Trabajo Final de Grado.

## 📋 Contenido

- **16 diapositivas** en formato HTML
- **Navegación interactiva** con controles visuales y teclado
- **Imágenes reales** de la aplicación integradas
- **Diseño responsivo** adaptado a diferentes pantallas

## 🚀 Cómo usar

### Opción 1: Abrir directamente
1. Descomprime el archivo ZIP
2. Abre el archivo `index.html` en tu navegador web preferido
3. ¡Listo! La presentación se cargará automáticamente

### Opción 2: Servidor local (recomendado para mejor rendimiento)
```bash
# Si tienes Python instalado
cd presentacion_completa
python -m http.server 8000

# Luego abre en tu navegador: http://localhost:8000
```

## ⌨️ Controles

### Navegación
- **Flecha derecha (→)** o **Espacio**: Siguiente diapositiva
- **Flecha izquierda (←)**: Diapositiva anterior
- **Home**: Ir a la primera diapositiva
- **End**: Ir a la última diapositiva

### Visualización
- **F**: Activar/desactivar pantalla completa
- **Esc**: Salir de pantalla completa

### Controles visuales
- Botones de navegación en la parte inferior
- Contador de diapositivas (X / 16)
- Barra de progreso en la parte superior
- Botón de pantalla completa (esquina superior derecha)

## 🎨 Características

- ✅ Navegación fluida entre diapositivas
- ✅ Diseño Swiss Grid Editorial profesional
- ✅ Capturas de pantalla reales de la aplicación
- ✅ Controles de teclado y visuales

- ✅ Sin dependencias externas (funciona offline)

## 💡 Consejos para la defensa

1. **Antes de empezar**: Presiona F para pantalla completa
2. **Durante la presentación**: Usa las flechas del teclado o la barra espaciadora
3. **Si necesitas volver atrás**: Usa la flecha izquierda
4. **Para salir**: Presiona Esc

## 🔧 Requisitos técnicos

- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- No requiere conexión a internet (todo está incluido)
- Resolución recomendada: 1280x720 o superior

## 📝 Notas

- Las diapositivas están optimizadas para formato 16:9 (1280x720px)
- Todas las imágenes usan rutas relativas (funcionan en cualquier ubicación)
- El diseño es completamente estático (no requiere servidor)
