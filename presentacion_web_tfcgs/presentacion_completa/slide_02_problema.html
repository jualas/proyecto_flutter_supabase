El Problema:
Gestión Descentralizada

La experiencia personal de gestionar un anteproyecto mediante documentos de Drive, conversión a PDF y burocracia manual, fue el origen de esta plataforma digital.
Origen del Proyecto
La idea surgió de mi experiencia personal con este proyecto: al recibir el modelo de anteproyecto en un documento de Drive que debía convertir a PDF y devolver al tutor, me planteé convertir este proceso en un software que gestionara los anteproyectos de forma eficiente.
Burocracia Analógica
Dependencia excesiva del papel y firmas físicas para la validación de anteproyectos, ralentizando el proceso y generando fricción innecesaria.
Evolución Orgánica
A partir de la idea inicial, el proyecto fue creciendo añadiendo funcionalidades según se identificaban necesidades: comunicación, gestión de proyectos, Kanban y sistema de roles.
